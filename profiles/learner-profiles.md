---
title: Who Is This Lesson For
---

This lesson is for learners who:

- Are comfortable with basic Linux command-line use (navigating directories,
  running commands, reading output)
- Have Docker Desktop or Docker Engine installed and working
- Want a hands-on, safe, legally-scoped environment to practice
  reconnaissance, scanning, exploitation, and post-exploitation techniques
- Are studying for a practical security certification (e.g. OSCP-style
  exams) or just starting a cybersecurity/pentesting learning path

No prior penetration testing experience is assumed for this pilot episode.
